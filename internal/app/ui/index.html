Harmonics

Pick a note, or play, and this follows it.

— 0.00

Each note carries a series of partials above it. Where two notes' partials land together they reinforce; where they land close but not together they beat, and that is roughness — measured here in semitones, so 1 is as rough as two notes a semitone apart. The cents say how far equal temperament has bent each interval from the whole-number ratio it is named after.

Where the numbers are printed. A long score being rehearsed wants them often and boxed; a song wants one at the head of each line.

Flute fingerings

Every fingering the instrument has, with how far out of tune it comes out. Pick a note; the standard chart is first and the alternates follow, nearest the chart first.

Engraving

What this score is engraved by, in staff spaces. The picture beside each one shows the distance it sets, in red. Every change shows on the page at once and belongs to this score, saved with it; empty a field to go back to the house style for that one. The numbers beside each are what most scores use, not a limit: set what you like. Cancel puts everything back the way it was when this window opened.

Lyrics

Type the verse as you would write it. The words are handed out to the notes in order, one syllable each. Break a word across notes with hyphens — Glo-ri-a — and hold a syllable over the next note with an underscore: A-men_ _. Rests are skipped.

Print

Choose what to print. Paper size, margins and “Save as PDF” are in your system’s print dialog, which opens next.

Settings

The language the menus and panels are written in.

A .gscore is a container. With this on it holds a PDF of the score as well as the music, so the same file renamed .pdf opens in anything that reads one — and anybody you send it to can read the score without gscore. With it off the file holds the music alone, and saving is quicker on a long piece.

Gscore

  

  
A musical score editor by Sébastien Tricaud.

  
Originally written in C and GTK+ between 2001 and 2005, the
     last release being 0.0.9 “harder, better, stronger, faster” in April 2005.
     Rewritten in Go in 2026, engraved with SMuFL and Bravura.

  
MIT licence. The music font is Bravura, under the SIL Open Font License.

  





  
Chord symbol

  

    
    
    

    

      
      
    

    
    
    
Filled in from the name for the usual chords. One
       character a string, lowest first: a fret number, or x for a string
       that is not played. Type your own and it stays yours; clear it to be
       offered one again.

Chord builder

One fret a string, lowest first, the way a chord diagram
     is written; x is a string that is not played. Type it or click it — the
     two follow each other. It is written at the cursor with whatever note
     value the toolbar is holding.

  

    
    
    
  




  
Text

  
Words beside the note that is selected. What kind of
     writing it is decides how it is set and where it goes — so every
     "rit." in the score comes out alike, and changes together.

  

    
    
    

    

      
      
      
    

  




  
Page setup

  
The paper this score is printed on. It is kept with the
     score, because it decides how wide a system may be and so how the
     music is laid out — not only how it comes out of the printer.

Lines that could not be read

  
A score file written by hand can hold a mistyped character,
     a wrapped line or a construction Gscore does not know. The music around it
     was read; these are the lines that were passed over, so that the file can
     be corrected at the source.

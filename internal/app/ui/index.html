Gscore

A musical score editor by Sébastien Tricaud.

Originally written in C and GTK+ between 2001 and 2005, the last release being 0.0.9 “harder, better, stronger, faster” in April 2005. Rewritten in Go in 2026, engraved with SMuFL and Bravura.

GPL v2 or later.

Chord symbol

Filled in from the name for the usual chords. One character a string, lowest first: a fret number, or x for a string that is not played. Type your own and it stays yours; clear it to be offered one again.

Lines that could not be read

A score file written by hand can hold a mistyped character, a wrapped line or a construction Gscore does not know. The music around it was read; these are the lines that were passed over, so that the file can be corrected at the source.
